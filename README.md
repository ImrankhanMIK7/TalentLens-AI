# TalentLens-AI
Analyze job market trends, identify in-demand skills, benchmark salaries, and optimize resumes using AI-powered analytics.

TalentLens-AI helps job seekers, students, and professionals analyze job market trends, identify in-demand skills, benchmark salaries, detect skill gaps, and optimize resumes with AI-powered analytics.

#🚀 Features
📈 Job Market Analytics
Analyze hiring trends across industries and locations.
Track job demand over time.
Visualize recruitment patterns through interactive dashboards.
💼 Skill Demand Analysis
Identify the most in-demand technical and soft skills.
Compare skill popularity across different job roles.
Discover emerging technologies in the market.
#💰 Salary Benchmarking
Compare salaries by:
Job Role
Experience Level
Location
Industry
Generate salary insights using historical and market data.
#📄 Resume ATS Scoring
Evaluate resumes using ATS-friendly parameters.
Calculate resume match score.
Highlight missing keywords.
Suggest improvements to increase interview chances.
#🎯 Skill Gap Detection
Compare resume skills with job descriptions.
Detect missing technical skills.
Recommend learning paths based on market demand.
📊 Interactive Dashboard
Real-time analytics dashboard built with Streamlit.
Dynamic charts and filters.
Data-driven insights for career planning.
