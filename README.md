# TalentLens-AI
Analyze job market trends, identify in-demand skills, benchmark salaries, and optimize resumes using AI-powered analytics.

## Features

- Job Market Analytics
- Skill Demand Analysis
- Salary Benchmarking
- Resume ATS Scoring
- Skill Gap Detection
- Interactive Dashboard

## Tech Stack

- Python
- Pandas
- PostgreSQL
- SQL
- Power BI
- Streamlit
- GitHub
